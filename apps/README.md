# Apps Directory — Curitiba 360 Enterprise Edition v1.0

Este repositório contém as aplicações da plataforma:
* `admin-backoffice` (Vite + React 19): Painel de gestão, Business OS e Governança
* `public-portal` (Next.js 15): Portal do Turista, SEO e Catálogo de Atrações
* `mobile-pwa` (Expo / React PWA): App mobile do Turista e Carteira Digital Pass
* `api-gateway` (NestJS): Gateway unificado, OAuth2, JWT e Rate Limiting
